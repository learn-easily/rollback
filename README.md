# Survive.cs

A 2D survival game that teaches C#. The robots took the world; you are the last human, guarding a Server they want. Learn C# from its assistant Echo, survive the nights, and build a time machine to undo it all. Every weapon, tool and building is unlocked by solving C# missions.

For students learning C# from zero to Junior level (ages 15–17 and up).

**Play:** https://learn-easily.github.io/zombify/

## How it works

- Click or tap to walk, gather, hunt and attack robots. WASD also works. Plays on desktop and on phones (portrait or landscape).
- **T** opens the terminal: missions, free practice and spaced-repetition review.
- **I** opens the Armory: inventory, shop and blueprints.
- Missions unlock buildings and gear. Story missions reveal bosses that carry time machine parts; each part opens the next Server level and chapter.
- Bytes, the upgrade currency, come only from answering questions. Robots drop scrap and circuits.
- Eat to survive: berries, hunting, cooking and farming.
- 75 challenges across chapters 1–3: Fundamentals, Conditions, Loops.

Progress is saved in the browser (`localStorage`), so every student keeps their own save.

## Tech

One self-contained `index.html`: Canvas 2D, no libraries, no server. The game design document is in [`docs/SURVIVE.md`](docs/SURVIVE.md).
